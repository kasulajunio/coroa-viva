# Fris Black Estúdio

Site de apresentação do Fris Black Estúdio, de Fabio. Substitui o antigo layout demonstrativo de login do Coroa Viva.

Site: https://kasulajunio.github.io/coroa-viva/

## Arquivos
- index.html: conteúdo sem dependências externas.
- styles.css: layout responsivo, temas escuro/claro e movimento reduzido.
- app.js: menu móvel, tema temporário e diálogos.
- favicon.svg: monograma FB original, marca e ícone de aba.

## Transparência
Não há login, cadastro, backend, pagamentos, formulário de contato ou catálogo de produtos concluídos. As frentes criativas apresentam áreas de interesse. Não publicar credenciais neste repositório.

O código não usa rastreadores, cookies próprios ou armazenamento local. O GitHub Pages pode manter registros técnicos segundo sua política. O tema não persiste após recarregar a página. A CSP está no HTML; frame-ancestors exige cabeçalho HTTP e não é prometido pelo site.

## Publicação e verificação
A URL foi preservada para evitar quebra de links. GitHub Pages: raiz da branch main. Verificar HTML, CSS, JS e SVG com status 200; navegação interna, menu móvel, tema, diálogos, teclado e ausência de rolagem horizontal.
